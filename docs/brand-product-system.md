# HeyDusk / 理想三旬：品牌、方向与独立产品

本文件维护品牌关系和轻量产品目录；核对日期 **2026-10-26**。产品合同、能力状态与验收证据继续由各产品仓维护。这里的摘要不是上线公告、真实家庭验收或共同法律政策。

## 层级

| 层级 | 定义 | 当前内容 |
|---|---|---|
| 企业 / 母品牌 | 小而独立的 AI 产品公司，对外统一的产品归属 | HeyDusk / 理想三旬；法律登记信息仅在确认后另行披露 |
| 业务方向 | 组织产品的分类，可以交叉，不设新品牌或事业部 | 家庭与生活；学习与成长；创作与表达 |
| 独立产品 | 各自解决具体需求，保持独立体验和发展节奏 | mimi / 小咪；Momo；FrameForge / 小片场（同一产品） |
| 交付形态 | 根据使用场景选择的入口 | iOS App、网页、插件、MCP；不是品牌层级 |
| 工程边界 | 各仓维护各自合同、实现与证据 | 不因品牌统一而合并产品、账号、数据或引擎 |

个人 AI / FDE 品牌与企业品牌并行；本轮不扩展为个人服务站。公司视觉保留 HeyDusk 黑白标识与 Last Light，mimi 保留橙奶油色小猫。

## 维护方式

- 本文件维护层级、名称关系、产品归属和来源；公司站 `apps/company/app/product-catalog.ts` 只维护中英文短摘要、已有入口和核对日期。不搬运各产品技术状态清单。
- 产品仓更新合同/验收后，按来源检查上述摘要，再更新官网；三个产品仓通过短链接回到本文件。新增产品或新站点必须有事实依据，不生成新域名或可用性承诺。
- 官网产品入口只能指向已有的产品页、插件说明或联系渠道。仓库源码不等于公开服务；未验证能力必须保留边界。
- 数据控制、儿童隐私和服务条款分别按产品核对。母站的 `/privacy`、`/terms` 仍是未法律审核、不生效的公司网站草案，不把 mimi 的承诺扩展为全产品政策。
- 轻量检查：`node scripts/check-brand-consistency.mjs`；各站保留自己的构建/渲染检查。本文件和脚本不创建平台服务、共享账号或数据层。
